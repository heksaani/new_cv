Selected projects

Classifying bacterial species from methylation patterns

Master's thesis, 2024–2025

Bacterial species are hard to tell apart in mixed microbial communities because their signals overlap. I developed a method that turns methylation signals from sequencing data into position weight matrices and classifies species with a Random Forest. It reached 94% species-level accuracy on real wastewater samples.

The work is part of a scientific publication (Markkanen et al., 2026). The analysis workflow is a version-controlled Python codebase in the publication repository.

  1. Sequencing reads with methylation calls
  2. Motif signals as position weight matrices
  3. Random Forest classifier
  4. Species per sample

Read the thesis Preprint on medRxiv Code on GitHub

Python, scikit-learn, pandas, Jupyter, Git

Cancer tissue of origin from mutational signatures

Team project, 2024

I led the technical side of a team project that predicts a tumour's primary tissue from its mutational signatures. I joined the team members' parts into one data pipeline, compared seven models (KNN, SVM, Random Forest, SGD, logistic regression, naive Bayes and MLP) and tuned their hyperparameters. A multi-layer perceptron performed best at 80% accuracy. I also brought Git into the team's workflow.

Python, scikit-learn, Plotly
